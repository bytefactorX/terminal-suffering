# Terminal Suffering - Text-Based Dungeon Crawler in C (WIP)

Terminal suffering is a simple, text-based dungeon crawler in C. Fight increasingly difficult enemies in turn-based combat and progress through increasingly frustrating dungeon levels to reach the end. 

## Requirements

- Linux system to build 
- gcc compiler

## Build & Run Steps

First, clone the repo: 

```
$ git clone https://github.com/bytefactorX/terminal-suffering.git
```

cd into the repo: 

```
$ cd teminal-suffering/
```

Finally, run the make command + run the executable:

```
$ make && ./game
```

To clean any build files, run this command in the game's directory:

```
$ make clean
```
